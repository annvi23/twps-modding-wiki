# 材料詞庫（英／日／中對照）

整理英文、日文教學時，用這份對照表統一用字。Claude 每次整理教學前先讀這份，遇到新詞整理完再補進來。

## 使用規則

1. **品牌與產品名保留原文**（不翻成中文），寫法照「標準寫法」那一欄，不要每篇各寫各的（例如 `Hi tec c`、`Hitec c`、`Hi-Tec` 一律寫成 `Hi-Tec C`）。
2. **零件、動作翻成中文**，用字照下面「零件與部位」「動作用語」兩張表。
3. 材料列寫法：`標準寫法（使用部位）：數量`。括號、冒號用全形；縮寫放在名稱後面的括號，例如 `Pentel Hybrid Gel Grip（HGG）（膠）：1`。
4. 長度一律 cm、重量一律 g（原文是 mm 就換成 cm，例如 8 mm → 0.8 cm）；不寫「約」。
5. 查不到、不確定的格子留空，不要猜。

## 補充詞庫的方式

整理一篇新教學時，遇到上面沒有的詞：

1. 先用原文拼法寫進教學草稿。
2. 草稿確認、上架後，把新詞和它在原文／本站的拼法加進對應的表。
3. 同一個東西如果發現有兩種以上寫法，選一個當標準寫法，其他放進「其他寫法」，並用搜尋把舊文改成標準寫法。
