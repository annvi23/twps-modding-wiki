# Eban Memory DC
![](https://penmodding.pm/wp-content/uploads/eban-dc-900x570.jpg)

### 相關數據
名稱：Eban Memory DC
發明者：未知
長度：21 cm
重量：12 g
Insert：待補充
原教學連結：待補充

### 所需材料
Monami Memory（筆桿、蓋子）：2
Supergrip（膠）：2
G–3（塑膠嘴）：2
Dr.grip（膠）：2 或 1

### 教學

#### 步驟一
切下平滑部分的SG膠
![](https://penmodding.pm/wp-content/uploads/IMG_20200102_180825-300x225.jpg)

#### 步驟二
放上G3膠嘴
![](https://penmodding.pm/wp-content/uploads/IMG_20200102_180855-300x225.jpg)

#### 步驟三
在SG膠外面套上一公分的Dr膠
![](https://penmodding.pm/wp-content/uploads/IMG_20200102_180922-300x225.jpg)

#### 步驟四
把筆蓋放到筆身上
![](https://penmodding.pm/wp-content/uploads/IMG_20200102_181006-300x225.jpg)
